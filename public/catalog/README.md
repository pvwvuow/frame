# کاتالوگ سرور نما (nama-catalog)

این پوشه **کاتالوگ کامل** برنامه‌ی نما را به‌صورت یک فایل مستقل نگه می‌دارد تا
بعداً بتوانید آن را روی سرور خودتان قرار دهید و برنامه از حالت آفلاین خارج شود.

## محتوا

- `index.json` — کل کاتالوگ: ۳۰۰ عنوان (فیلم + سریال) به‌همراه تمام قسمت‌ها،
  لینک‌های پخش، ژانرها، پوسترها و ...
- پوسترها و بک‌دراپ‌ها در پوشه‌ی `public/covers/<imdb>/` کنار همین پوشه قرار دارند
  (`poster.jpg` کوچک و `backdrop.jpg` بزرگ برای هر عنوان).

## راه‌اندازی سرور (سه قدم)

1. **آپلود**: فایل `index.json` و پوشه‌ی `covers` را روی هر هاست استاتیک
   (nginx، Cloudflare Pages، GitHub Pages، باکت S3 و ...) بگذارید؛ مثلاً:

   ```
   https://cdn.example.com/catalog/index.json
   https://cdn.example.com/covers/tt1234567/poster.jpg
   ```

2. **معرفی به برنامه**: در پوشه‌ی نصب برنامه (جایی که فایل `seed.db` هست،
   معمولاً `C:\Users\<نام‌کاربری>\AppData\Local\Programs\Nama\resources\app\`)
   یک فایل متنی ساده به نام `catalog-url.txt` بسازید و فقط آدرس فایل را داخلش بنویسید:

   ```
   https://cdn.example.com/catalog/index.json
   ```

3. **اجرای مجدد برنامه**: برنامه هنگام اجرا کاتالوگ را از سرور می‌خواند؛
   فقط وقتی محتوای سرور عوض شده باشد دیتابیس به‌روزرسانی می‌شود
   (هش محتوا چک می‌شود) و علاقه‌مندی‌ها/لیست تماشا/پروفایل دست‌نخورده می‌مانند.

## نکته‌ها

- تصاویر: اگر پوشه‌ی `covers` را کنار `index.json` روی سرور بگذارید، پوسترها از
  سرور خودتان لود می‌شوند؛ در غیر این صورت مسیرهای CDN در فیلد `posterUrl` /
  `backdropUrl` هر عنوان موجود است.
- لینک‌های پخش (videoUrl) مستقل از این سیستم‌اند و مستقیم به سرورهای دانلود
  (dls*.aparatchi-dlcenter.top) اشاره می‌کنند.
- تولید مجدد این فایل بعد از هر تغییر در کاتالوگ: `node scripts/export-catalog.mjs`
- نسخه‌ی فرمت: `format: "nama-catalog"` / `version: 1`
